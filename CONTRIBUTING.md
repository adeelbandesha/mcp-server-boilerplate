# Contributing to MCP Server Boilerplate

We welcome community extensions! To keep this repository production-grade, safe, and professional, please adhere to the following rules:

1. **No AI-Generated Code:** Do not submit PRs with hundreds of lines of chatty, obvious comments. Code must be clean and self-documenting.
2. **Type Safety:** All pull requests must pass strict TypeScript compilation (`npm run build`). No `any` types allowed.
3. **No Secret Hardcoding:** Never commit real API keys, Notion tokens, or environment credentials. Use `.env.example` templates only.
